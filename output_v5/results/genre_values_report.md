# ジャンル別ファン言説パターン分析

## 問い
HIPHOPのジャンル（Boom bap / Trap / Alternative）によって、ファンの「重視するポイント」は違うのか？
そして、それは商業的消費とどう関係するのか？

## 分析対象
- コメント総数: 21,018件（ノイズ除去後）
- ジャンル: Boom bap / Lyric, Trap, Alternative
- 分析手法: 相対比重アプローチ（詳細は下記参照）

## 最初のアプローチの失敗
「リリック重視」「Vibe」など5つの価値観カテゴリを定義し、1件のコメントを1つのカテゴリに分類しようとした。
**結果**: 90%のコメントが「その他」になり、失敗した。

## 気づき：饒舌さの差
| ジャンル | 平均コメント文字数 |
|---|---|
| Alternative | 90.5字 |
| Boom bap / Lyric | 102.8字 |
| Trap | 77.2字 |

ジャンル間でコメント文字数が大きく異なる（Boom bap > Trap）。
つまり、「Boom bapのファンはもっと色々な話をしている」というのは、
単なる「饒舌さの差」かもしれない。

## 解決策：相対比重アプローチ
1. コメント1件を「1カテゴリ」に分類するのではなく
2. 「リリック言及」と「Vibe言及」を**独立して**カウント
3. **両方に言及しているコメントの中で**、どちらの比重が高いか（相対比重）を見る

こうすることで、単なる饒舌さの差は除外できる。

## 主要結果
### 各ジャンルの値観言及率
| ジャンル | リリック | Vibe | 芸術性 | スタイル |
|---|---|---|---|---|
| Alternative | 4.1% | 8.3% | 5.9% | 3.7% |
| Boom bap / Lyric | 5.5% | 9.9% | 4.5% | 2.8% |
| Trap | 2.2% | 6.1% | 4.0% | 3.1% |

### 統計検定結果（カイ二乗検定）
| 値観 | χ² | p-value | 有意性 |
|---|---|---|---|
| リリック | 95.293 | 0.000000 | ✓ |
| Vibe | 63.962 | 0.000000 | ✓ |
| 芸術性 | 27.145 | 0.000001 | ✓ |
| スタイル | 12.467 | 0.001963 | ✓ |

## 商業的消費との接続
- **芸術性**: 映像・サンプリング・制作技術などの「作品の芸術的価値」への言及
  → **作品消費**（アートとしてのHIPHOP）
- **スタイル・ドリップ・ブランド**: 服装・アクセサリー・ライフスタイルの商品
  → **ブランド消費**（消費財としてのHIPHOP文化）

**解釈**: 
- Alternative系のファンは相対的に「作品消費」で語る傾向
- Trap / Boom bap系のファンは相対的に「ブランド消費」で語る傾向
つまり、**商業的消費の形がジャンルによって違う形で文化に組み込まれている**

## 結論
統計的に有意な差が検出されたことで、ジャンルごとの値観の違いは「単なる饒舌さの差」ではなく、
実際のファン文化の差異を反映していることが示唆された。
